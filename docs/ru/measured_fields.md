# Измеренные спектры стеклянных полей

[Предобработка](preprocessing.md) · [English](../en/measured_fields.md)

**Источник:** измерения автора на Meiji MT4300 и Olympus BX41 спектрометром Solar LS S100-2048H; см. [оборудование](hardware.md). Для каждой системы есть 97 стекол и осветитель. Во всех строках `Exposure.xlsx` стоит 100; запись о съемке указывает 100 мс для спектрометра. Это не таблица выдержек камеры.

**Формат:** три столбца приборного CSV — индекс, длина волны в нм, счеты. Сохраненный файл уже является экспортом прибора, хотя в записи описаны десять кадров сигнала и десять фона. Дополнительное вычитание вымышленного темнового спектра не выполняется. Счеты используются как относительный спектральный сигнал исследования; прослеживаемая коррекция чувствительности спектрометра не документирована.

1. [measured_fields.py](../../preprocessing/measured_fields.py) усредняет имеющиеся экспорты и делит на экспозицию, сохраняя `Average.csv` для каждого поля.
2. По осветителю выбирается непрерывный интервал от первого до последнего отсчета не ниже 5% максимума. Исторически это диапазон индексов, а не набор отдельных допустимых длин волн.
3. Рассчитываются **T(λ)=S_поля(λ)/S_осветителя(λ)** и **OD(λ)=−log10 T(λ)**. Исторический вариант сопоставляет одинаковые индексы; исправленный интерполирует осветитель на сетку поля и маскирует неположительные отношения. Значения T>1 отмечаются, но не обрезаются автоматически.
4. Для **диаграммы охватов** OD Meiji используется как характеристика стекол: D50, наблюдатель `2_2006`, интегрирование XYZ, затем xy. Исторически OD каждого стекла нормируется на собственный максимум; исправленный вариант не выполняет эту нормировку.
5. Для **калибровки** спектр прошедшего света каждого микроскопа интегрируется непосредственно с `10_2006`, а белой точкой служит его собственный измеренный осветитель. Это другой расчет, не сравнение охватов при общем D50. Исправленный вариант делит все XYZ и белую точку на одно Y осветителя и получает Lab напрямую; исторический сохраняет промежуточный переход через RGB.

В `<вариант>/<микроскоп>/` сохраняются спектры полей, `reference_xyz.csv`, `reference_lab.csv`, `whitepoint.json`, `spectral_quality.csv`, `processing.json`. Таблица качества показывает нефизические/комплексные OD и несовпадения сеток. Конечность результата не устраняет неопределенность съемки. Отсутствующие интервалы исключаются маской допустимости интегрирования, а не заменяются новыми измеренными сведениями.
