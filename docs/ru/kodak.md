# Kodak Q60

[Предобработка](preprocessing.md) · [English](../en/kodak.md)

**Вход:** `sources/targets/Color slides/Kodak Q60.xlsx`, 264 именованные тройки **XYZ в масштабе 0–100**. Это сохранившийся исследовательский источник. Конкретная партия, исходный адрес загрузки и полные условия измерения не установлены. Нельзя называть таблицу восстановленными спектрами пропускания или приписывать ей номер партии.

[reference_targets.py](../../preprocessing/reference_targets.py) создает `<вариант>/targets/kodak-q60.csv`. Исторический вариант сохраняет масштаб 0–100, исправленный делит значения на 100. Общий масштаб сокращается в `x=X/(X+Y+Z)` и `y=Y/(X+Y+Z)`, поэтому само это исправление не меняет оболочку.

Сравнение охватов сохраняет исходную трактовку таблицы. Для полного метрологического сопоставления нужно подтвердить белую точку и наблюдателя; одних этих троек недостаточно для обоснованного пересчета неизвестных условий к D50.
