# Изображения → средние RGB поля → Lab

[Предобработка](preprocessing.md) · [English](../en/images.md)

**Источник:** пронумерованные изображения автора в `measurements/<микроскоп>/images/<поле>/`. Meiji — BMP, Olympus — JPEG. Для каждого поля имеется несколько полных кадров. Скриншоты и старые превью не входят в среднее.

1. [image_fields.py](../../preprocessing/image_fields.py) открывает числовые изображения как RGB, усредняет пиксели внутри кадра, затем средние кадров с одинаковыми весами. Выделение ROI и искусственная замена отсутствующих изображений не выполняются.
2. Сохраняются именованные **RGB в масштабе 0–255** и запись кэша. Отпечаток кэша включает имена, размеры и время изменения файлов; для безусловного пересчета после замены изображений удалите `artifacts/images`.
3. Загружается белая точка того же микроскопа. Историческое преобразование намеренно передает вещественные 0–255 в прежний расчет Lab. Исправленный вариант сначала делит их на 255.
4. Сохраняется `<вариант>/<микроскоп>/registered_lab.csv`; сопоставление со спектральными Lab выполняется по точным именам полей.

Исправленное преобразование **предполагает кодирование sRGB**. Отключенная галочка гаммы в интерфейсе не доказывает линейность сохраненных данных и не задает цветовой профиль камеры. Без измеренной характеристики кодирования/отклика это остается явным допущением, а не полной физической коррекцией.

Нельзя выводить выдержки камеры из спектрометрического `Exposure.xlsx`. В нем все значения равны 100, поэтому прежний относительный множитель 100/100 был единицей. Новый расчет не применяет чужую таблицу экспозиций к RGB изображений.

В блокноте выбранный Lab-полином дополнительно применяется ко всем пикселям одного изображения стеклянного поля для каждого микроскопа. Равномерный спектральный эталон — превью цвета, не измеренное пространственное эталонное изображение. RGB ограничивается только для просмотра; ΔE рассчитывается по Lab без этого ограничения.
