# Стандартные наблюдатели и осветители

[Предобработка](preprocessing.md) · [English](../en/observers.md)

**Формат:** строки CSV `длина_волны_нм, x_bar, y_bar, z_bar`. Это весовые функции наблюдателя, не цвета полей. Таблицы D50/D65 содержат длину волны и относительную спектральную мощность.

Сохранены шесть исследовательских обозначений:

| Ключ | Локальный файл | Назначение |
|---|---|---|
| `2_1931` | `ciexyz31.csv` | CIE 1931 2°; цветной фон диаграммы |
| `10_1964` | `ciexyz64.csv` | CIE 1964 10°; сохранен для сравнения |
| `2_1951` | `ciexyzj.csv` | Поправка Judd; сохранена |
| `2_1978` | `ciexyzjv.csv` | Поправка Judd–Vos; сохранена |
| `2_2006` | `lin2012xyz2e_fine_7sf.csv` | Физиологически обоснованные XYZ 2°; охваты |
| `10_2006` | `lin2012xyz10e_fine_7sf.csv` | Физиологически обоснованные XYZ 10°; спектральные эталоны калибровки |

Исторический источник загрузки — [CVRL](http://www.cvrl.org/ciexyzpr.htm). Имена `lin2012xyz...` соответствуют таблицам XYZ для [2°](http://www.cvrl.org/database/text/cienewxyz/cie2012xyz2.htm) и [10°](http://www.cvrl.org/database/text/cienewxyz/cie2012xyz10.htm), полученным из фундаментальных функций колбочек CIE 2006. Обозначение `2006` **не** означает CIE 1931. Более поздний стандарт — [CIE 170-2:2015](https://cie.co.at/publications/fundamental-chromaticity-diagram-physiological-axes-part-2-spectral-luminous).

Признанный современный источник CIE 1931 — [официальный набор CIE для наблюдателя 2°](https://cie.co.at/datatable/cie-1931-colour-matching-functions-2-degree-observer). Его сетка 1 нм не подменяет архивную сетку 5 нм, использованную для воспроизведения фона. Еще два архивных файла сохраняются без изменения, но не выбираются блокнотами.

[observers.py](../../preprocessing/observers.py) копирует таблицы в `artifacts/observers/` без пересчета сетки и записывает контрольные суммы. Интерполяция выполняется только при конкретном интегрировании. D50 и D65 — сохраненные исследовательские табуляции стандартных осветителей в `sources/reference/`; расчет читает подготовленные файлы из `artifacts/observers/`; исходные комментарии ссылаются на R. W. G. Hunt, *Measuring Colour*, 2-е издание, Ellis Horwood, Chichester, 1991. Точный адрес загрузки не установлен. Для сравнения мер используется D50, для калибровки — измеренный осветитель соответствующего микроскопа, а CIE 1931/D65 используется только для цветного фона.
