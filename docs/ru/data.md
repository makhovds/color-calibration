# Данные и архивы

[README](../../README.ru.md) · [English](../en/data.md)

Файлы размещаются в [папке данных исследования](https://disk.yandex.ru/d/D495fZYlgSzGCA).

| Архив | Содержимое | Для чего нужен |
|---|---|---|
| `spectra-and-references.zip` | `sources/`, спектры обоих микроскопов, таблицы экспозиции | Спектры, меры и расчет охвата |
| `microscope-images.zip` | Пронумерованные изображения полей обоих микроскопов | Полный блокнот и калибровка |
| `misc.zip` | DOCX режимов, скриншоты, проекты прибора, сохраненная обработка, исходные заметки | Понимание и проверка исследования |
| `artifacts.zip` | Новые CSV/JSON/PNG/SVG, выполненные блокноты, интерактивные HTML | Просмотр без повторного расчета |
| `original-research-code.zip` | Неизмененные исследовательские коды и добавленный путеводитель | Историческая реализация |

Первые три архива объединяются в **одну** папку `color-calibration-data`. `artifacts.zip` распаковывается в каталог репозитория, а не внутрь данных. Архив исходных кодов независим. Приложенные манифесты SHA-256 позволяют проверить тождественность файлов; контрольная сумма не подтверждает точность измерения.

```text
color-calibration-data/
  sources/
    camera/                общий график, каналы, маски, сохраненные CSV
    observers/             исходные функции соответствия цветов
    dyes/                  18 файлов длина волны / OD
    targets/               таблицы координат и рисунок Bautista
    calibration/           архивные Lab для независимого сравнения
    reference/             осветители и порядок полей
  measurements/
    meiji/                 Exposure.xlsx, spectra/<поле>/, images/<поле>/
    olympus/               та же структура
  misc/
    acquisition/           режимы, скриншоты, проекты прибора
    saved-processing/      прежние результаты, не входы блокнотов
    original-python/       исходный полиномиальный эксперимент
    dye-source-files/      более ранние файлы красителей
    papers/                локальные авторские копии для сверки
```

Имена полей являются точными идентификаторами, в том числе на кириллице. Есть 97 цветных стекол и `Осветитель`. Не переименовывайте поля и не объединяйте их файлы в одну папку. Исходный спектральный CSV содержит индекс, длину волны в нм и счеты; используются два последних столбца. Подготовленные спектры имеют два столбца без заголовка. Таблицы цветов содержат `Name` и три столбца координат.

Усредняются только изображения с числовыми именами; скриншоты, графики и превью исключены. У Meiji 579 BMP, у Olympus 711 JPEG, по 98 папок полей. Средние кэшируются. Для повторного декодирования удалите `artifacts/images`.

Состав отражает сохранившиеся файлы, а не гарантированно полный набор съемки 2021 года. Происхождение сторонних данных описано отдельно; наличие локального файла само по себе не подтверждает разрешение на его дальнейшее распространение.
