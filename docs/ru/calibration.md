# Воспроизведение полиномиального эксперимента

[Предобработка](preprocessing.md) · [English](../en/calibration.md)

В [статье IOP](https://doi.org/10.1088/1742-6596/2192/1/012010) зарегистрированные цвета каждого микроскопа приводятся к его собственным спектральным эталонам в **CIE Lab**. Такое направление отдельно воспроизводится для Meiji и Olympus.

1. `registered_lab.csv` сопоставляется с `reference_lab.csv` по имени поля. Исторически участвуют 97 полей **и осветитель**, как в сохраненных 98-строчных таблицах. Исправленный вариант исключает осветитель из обучения.
2. Методом наименьших квадратов обучаются степени 1–5 с перекрестными членами и без них. Полная модель содержит все мономы суммарной степени не выше выбранной и свободный член.
3. Историческая модель без перекрестных членов обучает каждый выход только по соответствующему входному каналу: L по степеням L, a по степеням a, b по степеням b. В статье описаны аддитивные признаки всех каналов; исправленная модель без перекрестных членов следует этой печатной формуле.
4. Для демонстрации изображений сохранен выбор статьи: степень 3 с перекрестными членами для Meiji, степень 4 для Olympus. Он не меняется автоматически, даже если исправленный расчет или отложенная оценка предпочитают другую степень.
5. Сохраняются коэффициенты и параметры центрирования/масштаба, сравнения степеней и ошибки полей. Архивные таблицы аппроксимируются отдельно для независимой сверки и не подменяют пересчет из изображений и спектров.

Для поля i стандартное **ΔE76ᵢ = sqrt(ΔLᵢ² + Δaᵢ² + Δbᵢ²)**; затем эти расстояния усредняются. В исходной программе использовано **(sqrt(ΣΔLᵢ²) + sqrt(ΣΔaᵢ²) + sqrt(ΣΔbᵢ²))/N**. Эти формулы различаются. Последняя воспроизводит 0.75 и 0.66, но не должна называться средним ΔE76.

В исправленном варианте входы центрируются и масштабируются, рассчитывается обычное ΔE76 и добавлена детерминированная пятикратная проверка на отложенных полях с seed 2021. Параметры масштаба вычисляются внутри обучающей части каждого разбиения. Отложенными являются **поля**, не независимые сеансы съемки или препараты тканей. Очень большие ошибки степени 5 остаются видимыми. Рост исторической ошибки обучения при высокой степени сам по себе не доказывает переобучение: влияют обусловленность и численный ранг.

Изображения до/после иллюстрируют применение модели, обученной на полях. Ошибка пикселей относительно равномерного эталона отличается от ошибки среднего цвета поля. Пространственный эталон пикселей отсутствует; проверка на окрашенной ткани не заявляется.
