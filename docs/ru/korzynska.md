# Сравнение Korzynska / Rosco

[Предобработка](preprocessing.md) · [English](../en/korzynska.md)

**Сохраненные ссылки:** Korzynska и соавт., [DOI 10.1109/IST.2016.7738196](https://doi.org/10.1109/IST.2016.7738196), и [Rosco myColor](https://emea.rosco.com/en/mycolor). В исследовательском коде находятся восемь троек **Lab**: красный, зеленый, синий, желтый, янтарный, белый, серый и коричневый. Измеренных спектров этих полей нет.

[reference_targets.py](../../preprocessing/reference_targets.py) через `analysis/charts.py` сохраняет восемь троек, трактует Lab относительно осветителя A и адаптирует XYZ из A в D50. Выход: `<вариант>/targets/korzynska-d50.csv`. Исправленный вариант уточняет обратную матрицу Bradford, но не устраняет неопределенность исходной трактовки.

Соответствие троек номерам фильтров производителя, исходная белая точка и точность переноса чисел не могут быть независимо установлены по сохраненным материалам. **Осветитель A — унаследованное допущение.** Этот набор можно включать дополнительно в интерактивной диаграмме; при использовании покрытия следует раскрывать данное допущение.
